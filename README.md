# FastAPI Azure DevOps Starter

A simple FastAPI application designed for Azure DevOps CI/CD learning.

## 🚀 Features
- FastAPI app
- Pytest unit tests
- Azure DevOps YAML pipeline
- Ready for multi-stage CI/CD
- Deployable to Azure App Service
